About

This is a silly little website I built in a day. It was mainly inspired by the work of the NBA Research & Development Department (@nbaresdev) and their website nbatop80.com, because I always enjoy seeing rankings that aren't super serious and are more community oriented. Also the only time we usually get to see data like this is during all-star voting. Now it's like all-star voting forever, and we see all the rankings!!!

You can find more of my work here and you can see the source code for this project on the Github repo. Feel free to reach out if you have any questions or suggestions or just want to say hi!
